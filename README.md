# StudyPlanner
Une application de gestion de tâches pour étudiants.

## Utilisateurs cibles
Les étudiants qui gèrent leurs cours et leurs échéances.

## Fonctionnalités
- Créer des tâches avec un titre, une échéance et une priorité
- Afficher toutes les tâches dans une liste
- Marquer les tâches comme terminées
- Filtrer les tâches par matière
- Définir des niveaux de priorité (basse / moyenne / haute)

## Stack technique
- Next.js (framework React)
- Déployé sur Vercel
## User stories
« En tant qu'étudiant, je veux créer des tâches avec une échéance, afin de suivre mes devoirs. »
« En tant qu'étudiant, je veux marquer des tâches comme terminées, afin de voir ma progression. »
« En tant qu'étudiant, je veux filtrer les tâches par matière, afin de me concentrer sur un cours à la fois. »
« En tant qu'étudiant, je veux définir des niveaux de priorité, afin de savoir par quelles tâches commencer. »
« En tant qu'étudiant, je veux voir la liste de toutes mes tâches, afin d'avoir une vue d'ensemble de ma charge de travail. »
